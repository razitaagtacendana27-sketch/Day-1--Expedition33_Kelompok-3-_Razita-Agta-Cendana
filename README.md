# Day 1 - Workshop From AI to GitHub

## 1. Rangkuman Materi

### A. Workshop "From AI to GitHub"

Workshop membahas mengenai membuat dan mengembangkan aplikasi dengan bantuan AI, serta mengelola perubahan dan kolaborasi dengan Git dan GitHub.

#### a. Prompt Engineering

Prompt adalah indtruksi yang diberikan kepada AI untuk mendapatkan hasil tertentu. Prompt Engineering adalah cara menyusun instruksi agar jawaban AI tepat dan sesuai yang kita inginkan atau harapkan, serta agar membuat AI lebih paham mengenai instruksi yang diberikan.

Struktur prompt yang baik terdiri dari empat bagian, yaitu:

1. **Role:** peran yang diminta dari AI
2. **Task:** tujuan atau tugas Utama
3. **Context:** kebutuhan dan Batasan
4. **Format:** bentuk hasil yang diinginkan.

#### b. Git dan GitHub

Git adalah version control system yang mencatat siapa, kapan, dan apa yang diubah pada sebuah file. GitHub adalah platform berbasis web atau cloud untuk menyimpan repository Git secara online dan mendukung kerja sama.

Perubahan file di Git melewati tiga area:

1. **Working directory:** tempat file dikerjakan.
2. **Staging area:** daftar perubahan yang akan disimpan di commit berikutnya.
3. **Repository:** tempat riwayat proyek disimpan.

Ada juga istilah yang perlu diketahui, yaitu git init untuk memulai repository, git add untuk memindahkan perubahan ke staging area, git commit untuk menyimpan perubahan, git push untuk mengirim perubahan ke GitHub, git pull untuk mengambil perubahan dari GitHub, dan git clone untuk menyalin repository dari GitHub.

### B. Pengenalan Akademik Jurusan TIK

#### a. Layanan Laboratorium

**Alur untuk peminjaman alat:**

**Dipakai di lab:** hubungi teknisi, tinggalkan KTM sebagai jaminan, teknisi menyerahkan alat, alat dipakai di lab, lalu dikembalikan dan KTM diambil kembali.

**Dibawa pulang:** isi Form Peminjaman Alat, minta tanda tangan Kepala Lab (Kalab), serahkan form ke teknisi, lalu teknisi memeriksa kelengkapan dan menyerahkan alat.

**Alur untuk peminjaman ruangan:**

1. Konfirmasi rencana peminjaman ke teknisi/admin lab.
2. Teknisi/admin memeriksa jadwal.
3. Jika jadwal penuh, pilih waktu lain.
4. Jika jadwal kosong, ajukan ke Kalab untuk mendapat persetujuan (ACC).
5. Konfirmasi slot peminjaman ke teknisi/admin.

#### b. Tata Tertib Mahasiswa

**Alur penanganan pelanggaran:**

dosen menegur mahasiswa lebih dulu. Jika tidak ada perubahan, dosen melapor ke Ketua Program Studi (KPS) untuk pembinaan. Jika masih tidak berubah, KPS memanggil orang tua/wali, dibuat kesepakatan tindak lanjut, dan dilakukan pemantauan. Jika tetap tidak ada perubahan, mahasiswa dikenai sanksi sesuai ketentuan.

**Ketentuan penampilan rambut:**

Pendek dan rapi, tidak melebihi kerah baju, tidak menutupi telinga, serta bersih dan terawat. Tidak diperkenankan rambut yang menutupi dahi atau mata, menutupi telinga, atau diikat karena terlalu Panjang.

### C. Struktural Jurusan TIK

Jurusan Teknik Informatika dan Komputer (TIK) Politeknik Negeri Jakarta dipimpin oleh Ketua Jurusan, dibantu Sekretaris Jurusan dan Admin Jurusan. Di bawahnya ada:

- Empat Kepala Program Studi: TI, TMJ, TMD, dan RKS. Masing-masing prodi punya admin sendiri.
- Dua Kepala Laboratorium: Lab Komputer dan Jaringan, serta Lab Cyber Security.

### D. Profil Lulusan Prodi TI

Kurikulum OBE 2026 prodi TI memuat 49 mata kuliah dengan 145 SKS dalam 8 semester. Kurikulum disusun "mundur", yaitu dari profil lulusan, ke profesi, ke capaian pembelajaran lulusan (CPL), lalu ke mata kuliah.

**Cara belajar yang disarankan:**

1. Membaca ulang adalah cara terbaik.
2. Belajar kebut semalam sudah cukup.
3. Belajar yang baik harus bebas salah.
4. Setiap orang punya satu gaya belajar tetap.

### E. Profil Lulusan dan Kurikulum Prodi TMD

Kurikulum OBE 2026 prodi TMD memuat 55 mata kuliah dengan 144 SKS dalam 8 semester. OBE (Outcome-Based Education) artinya kurikulum disusun dari kemampuan yang harus dimiliki lulusan.

**Visi keilmuan:** menjadi program studi bertaraf internasional di bidang game, animasi, dan multimedia interaktif untuk mendukung daya saing bangsa.

**Misi:**

1. Menyelenggarakan pendidikan Teknik Multimedia Digital yang unggul di Indonesia dan diakui dunia.
2. Mengembangkan penelitian dan pengabdian masyarakat terapan yang kreatif dan inovatif.
3. Mengembangkan layanan pendidikan yang berkinerja prima dan akuntabel berbasis teknologi informasi.
4. Membangun kerja sama dengan mitra industri dan non-industri tingkat nasional dan internasional.

### F. Profil Lulusan Prodi TMJ

144 SKS. Profil lulusannya adalah jaringan komputer, IoT, infrastruktur dan keamanan TI, pengembangan aplikasi, dan technopreneur.
